# Agents work on documents they cannot read

Finds, masks, and proves data is gone — in your browser, never the agent.
## Privacy boundary — the agent orchestrates, the browser executes

Redacta splits the work in two. Your agent decides what should happen — scan
these categories, redact these findings, verify, export. The browser does all
of it locally and answers with metadata only, so the values that made the
document confidential never cross the boundary.

What the agent receives (metadata only):
  Category       credit_card
  Page           3
  Confidence     0.98
  Status         redacted
  Verification   passed

What it never receives:
  Social Security   123-45-6789
  Card number       4111 1111 1111 1111
  API key           sk_live_51NORTHSTAR
  Document text     Employment Agreement…
  Artifact bytes    1.04 MB PDF
## How it works — three things have to be true, or it isn't privacy

### 1. Detection that never leaves the tab
Regex candidates are confirmed by structural validation — Luhn, SSN ranges,
key and connection-string shapes — then scored. The pass runs in a Web Worker,
so a long document stays interactive.
detectors: ssn, credit_card, email, phone, api_key, private_key,
           bearer_token, db_connection_string
example: 17 findings · 7 ssn · 3 credit_card · 5 email · 2 api_key

### 2. Masks that survive a copy and paste
A black rectangle drawn over live text is not a redaction. Redacta renders
every page, bakes padded masks into the pixels, and rebuilds an image-only
PDF — the sensitive glyphs are gone, not covered. Whole overlapping text items
are masked, so interpolated character geometry can't leak an edge.
result: text layer removed · masks baked into the page image

### 3. Proof taken from the artifact, not the UI
Verification re-reads the generated file and rescans its bytes, checks that no
original detected value survives, and separately checks that every detected
region is covered. All three must pass before export unlocks. Export re-checks
the artifact digest so a file that changed after verification can't be
downloaded as verified.
result: extractable: 0 · unmasked regions: 0 · original values: 0 · export unlocked
"The agent knows there are seven SSNs. It never knows what those SSNs are."
