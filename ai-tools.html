## What WebMCP is doing here

WebMCP is how Redacta talks to an agent without handing it the file. The
agent does not scrape the DOM and it is not given the PDF. It is offered
ten named operations — inspect, scan, redact, verify, export — and every
answer is metadata. The tool API is the privacy boundary.
## How it is built

### Registration — src/ui.js
registerTools() looks for document.modelContext.registerTool, then
navigator.modelContext.registerTool. Each tool is registered with name,
description, inputSchema, and execute. Agent calls go through
executeTool(name, input, "agent").

modelContext.registerTool({
  name,
  description: TOOL_DESCRIPTIONS[name],
  inputSchema: TOOL_SCHEMAS[name],
  execute: (input) => execute(name, input)
});

### Schemas — src/tools.js
TOOL_SCHEMAS and TOOL_DESCRIPTIONS live next to the implementations.
Every description states the tool never returns document contents or
sensitive values.

### Privacy projection — src/registry.js
Raw detector hits stay in an in-memory registry. Anything that crosses
to the agent is projected through SAFE_FIELDS:
  id, type, confidence, status, origin, page
Values, locations, and offsets are not on that list.

### Confirmation — src/ui.js requestConfirmation
When callSource is "agent", applyRedactions, exportSanitizedDocument,
registerCustomPattern, and redactField call in-page requestConfirmation.
Deny, or wait out the minute, and the tool returns denied.

### Demo Mode fallback
If native WebMCP is missing, the same ten functions are assigned onto
window and callable from the Console pane. Same schemas, same projection,
same confirmation gate.

### Verification — src/verify.js
Verification re-reads the generated artifact bytes and reports three
independent checks:
  extractableFindings   detectors still fire on the artifact
  unmaskedRegions       findings still marked pending
  originalValuesFound   original raw strings still appear
Export is blocked until all three are zero. Export then re-checks the
SHA-256 digest so a file changed after verification cannot download as
verified.
## The ten tools — what the agent gets vs never gets

inspectDocument({})
  Status check, not a read.
  Gets: fileType, filename, documentSize, pageCount, processingStatus.
  Never: a character of the document.

scanDocumentPII({categories?})
  Local detectors, optional category scope, Web Worker.
  Gets: totalDetected, findings[{id, type, confidence, status, origin, page}].
  Never: matched values, locations, or offsets.

getFindingDetails({findingId})
  One finding, same whitelist.
  Gets: type, confidence, status, origin, page.
  Never: value, location, or character offsets.

applyRedactions({targetIds?, maskMode?})
  Marks findings redacted and builds a local artifact.
  Requires human approval when callSource is agent.
  Gets: totalRedacted, maskMode, projected findings.
  Never: document contents or the masked strings.

verifyRedaction({categories?})
  Re-reads artifact bytes. App state is not proof.
  Gets: passed, remainingFindings, extractableFindings, unmaskedRegions,
        originalValuesFound, per-category counts.
  Never: remaining values or document text.

exportSanitizedDocument({filename?})
  Local download of the verified artifact.
  Requires human approval. Blocked until verification passes.
  Gets: filename, size, verified: true.
  Never: the file bytes in the tool response.

getVerificationCertificate({})
  Metadata-only proof for a passing artifact (RDCT-… id, digest, counts).
  Gets: certificateId, digest, document metadata, check counts.
  Never: document contents or finding values.

registerCustomPattern({name, pattern, flags?})
  Validates a regex, registers a local detector (max 5).
  Requires human approval. Unsafe / empty / slow patterns are rejected first.
  Gets: name, totalPatterns.
  Never: document contents or later match values.

listStructuredFields({})
  JSON keys or CSV columns only.
  Gets: format, fields[{field, occurrences, detectedFindings}].
  Never: cell or leaf values.

redactField({field, maskMode?})
  Redacts every string value of one JSON key or CSV column.
  Requires human approval.
  Gets: field, valuesRedacted, redactedIds, totalRedacted, projected findings.
  Never: the values that were redacted.

## How to try it

1. ChatGPT in-app browser (WebMCP on by default), or Chrome 149+ with
   chrome://flags/#enable-webmcp-testing enabled, then restart Chrome.
2. Open ./app.html. No account. No backend.
3. Open a PDF, TXT, JSON, or CSV, or click Run agent demo to load
   the synthetic contract. The file stays in the tab.
4. Click Run agent demo, or use the Console pane. With native WebMCP,
   paste the Agent-pane prompt into ChatGPT.
5. Mutating calls stop for in-page confirmation. Export stays locked
   until extractableFindings, unmaskedRegions, and originalValuesFound
   are all zero.
