# Let agents work on documents they are never allowed to read

Redacta finds the sensitive data in a confidential file, masks it, and proves
it is gone — entirely inside your browser. WebMCP hands your agent the
controls, never the contents.

PDF · TXT · JSON · CSV — 0 bytes leave the tab

  0  bytes of your document uploaded
  7  WebMCP tools registered
  8  detector categories, locally run
  2  independent checks before export
## Privacy boundary — the agent orchestrates, the browser executes

Redacta splits the work in two. Your agent decides what should happen — scan
these categories, redact these findings, verify, export. The browser does all
of it locally and answers with metadata only, so the values that made the
document confidential never cross the boundary.

What the agent receives:
  type: "credit_card"      category
  page: 3, region C        location
  confidence: 0.98         score
  status: "redacted"       state
  passed: true             verification

What it never receives:
  ████████████  the SSN
  ████████████  the card number
  ████████████  the API key
  ████████████  document text
  ████████████  artifact bytes
## How it works — three things have to be true, or it isn't privacy

### 1. Detection that never leaves the tab
Regex candidates are confirmed by structural validation — Luhn, SSN ranges,
key and connection-string shapes — then scored. The pass runs in a Web Worker,
so a long document stays interactive.
detectors: ssn, credit_card, email, phone, api_key, private_key,
           bearer_token, db_connection_string
example: 17 findings · 7 ssn · 3 credit_card · 5 email · 2 api_key

### 2. Masks that survive a copy and paste
A black rectangle drawn over live text is not a redaction. Redacta renders
every page, bakes padded masks into the pixels, and rebuilds an image-only
PDF — the sensitive glyphs are gone, not covered. Whole overlapping text items
are masked, so interpolated character geometry can't leak an edge.
result: text layer removed · masks baked into the page image

### 3. Proof taken from the artifact, not the UI
Verification re-reads the generated file, extracts its text and rescans those
bytes, then separately checks that every detected region is actually covered.
Both must pass before export unlocks, and export re-checks the artifact digest
so a file that changed after verification can't be downloaded as verified.
result: extractable: 0 · unmasked regions: 0 · export unlocked
## Guarantees — enforced in code, visible in the interface

- Local-only processing. Parsing, detection, masking, verification and export
  all run in the page. Nothing is posted to a server.
- No values in tool results. A fixed safe-field whitelist projects every
  finding; raw matches stay in a private in-memory registry.
- Human approval to mutate. Agent-requested redaction and export both stop for
  an in-page confirmation with a visible timeout.
- Byte-level verification. The exported artifact is rescanned, and mask
  coverage is checked separately — app state is never treated as proof.
- Verified-only export. Failed verification blocks the download and says how
  many findings remain. Redacta never claims a file is clean when it isn't.
- Measured network activity. A live counter reports outbound requests made by
  the page. During a full demo run it stays at zero.
## WebMCP surface — seven tools, capabilities not contents

Registered on document.modelContext when native WebMCP is available, with a
Demo Mode console when it isn't — the same tools, the same boundary.

inspectDocument({})
  → fileType, pageCount, documentSize, processingStatus.  No text.
scanDocumentPII({categories?})
  → totalDetected, findings[{id, type, page, location, confidence}].
    No matched values.
getFindingDetails({findingId})
  → one projected finding, including its boundingBox.  Still no value.
applyRedactions({targetIds?, maskMode?})
  → totalRedacted.  Requires human approval.
verifyRedaction({categories?})
  → passed, remainingFindings, extractableFindings, unmaskedRegions,
    per-category counts, syntheticPlaceholders, originalValuesFound.
exportSanitizedDocument({filename?})
  → filename, verified.  Blocked until verification passes.

getVerificationCertificate({})
  metadata-only certificate for a verified artifact.  No contents or values.
