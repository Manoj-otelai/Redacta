Privacy boundary

The agent orchestrates. The browser executes.

Redacta splits the work in two. Your agent decides what should happen — scan these categories, redact these findings, verify, export. The browser does all of it locally and answers with metadata only, so the values that made the document confidential never cross the boundary.

How it works

Three things have to be true, or it isn't privacy

Detection that never leaves the tab

Regex candidates are confirmed by structural validation — Luhn, SSN ranges, key and connection-string shapes — then scored. The pass runs in a Web Worker, so a long document stays interactive.

Rasterized exporttext layer removed · masks baked into the page image

Masks that survive a copy and paste

A black rectangle drawn over live text is not a redaction. Redacta renders every page, bakes padded masks into the pixels, and rebuilds an image-only PDF — the sensitive glyphs are gone, not covered.

Export a sanitized copy →

Whole overlapping text items are masked, so interpolated character geometry can't leak an edge.

Verificationextractable: 0 · unmasked regions: 0 · export unlocked

Proof taken from the artifact, not the UI

Verification re-reads the generated file, extracts its text and rescans those bytes, then separately checks that every detected region is actually covered. Both must pass before export unlocks.

Read the guarantees →

Export re-checks the artifact digest, so a file that changed after verification can't be downloaded as verified.

Guarantees

Enforced in code, visible in the interface

Open the workspace

Local-only processing. Parsing, detection, masking, verification and export all run in the page. Nothing is posted to a server.

No values in tool results. A fixed safe-field whitelist projects every finding; raw matches stay in a private in-memory registry.

Human approval to mutate. Agent-requested redaction and export both stop for an in-page confirmation with a visible timeout.

Byte-level verification. The exported artifact is rescanned, and mask coverage is checked separately — app state is never treated as proof.

Verified-only export. Failed verification blocks the download and says how many findings remain. Redacta never claims a file is clean when it isn't.

Measured network activity. A live counter reports outbound requests made by the page. During a full demo run it stays at zero.
